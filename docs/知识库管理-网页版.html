如何避免 Wiki 多人协作冲突

不靠锁、不靠短事务；让冲突自动合并 / 可机械秒解

①
消灭状态
index 本地缓存不提交
  • index 是投影（删后可零丢失再生），非数据
  • 降为本地缓存，gitignore 不提交
  • 头号冲突热点直接消失；pull 后确定性重建
不提交，即无冲突
②
错开写入
结构错开，git 行级合并
  • git 事实：两人都往文件尾追加 = 同锚点不同插入，必冲突
  • log 按来源分小节、排序插入（不堆文件尾）
  • 页面一页一物文件级隔离，并发写入落不同区域
落在不同区域，合并自动通过
③
冲突无害化
可机械秒解
  • log append-only：冲突两边条目全保留、按时间戳排序
  • 确定性规则，AI 可机械执行，无需人工裁决
  • 仍频繁冲突 → 升级 log 目录化（一次 ingest 一文件，零冲突）
并发必发生，冲突可秒解
